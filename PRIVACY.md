# Privacy

ChopHop runs only on `https://www.youtube.com/watch*` pages.

It stores watch-path drafts in your browser using Chrome local storage. Shared watch paths contain only a YouTube video ID and selected timestamps in the URL fragment. The fragment is not sent to YouTube by the browser.

ChopHop does not collect accounts, cookies, video content, transcripts, viewing history, or analytics. It makes no network requests.

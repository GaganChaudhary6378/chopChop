# Store listing draft

## Name

ChopHop

## Short description

Tell an agent what matters. Share only those video moments.

## Full description

ChopHop turns clear time instructions into a YouTube watch path. Ask for ranges such as “keep 0:30 to 2:10, then 7:45 to 9:00.” Review the proposed path, apply it, and copy one link. Friends with ChopHop installed open the same video with the same selected moments.

ChopHop never edits, downloads, or uploads YouTube videos. Your paths stay in browser storage until you choose to share a link.
